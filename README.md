game name(currently): "officer's charge"
inspired by roblox game "guts and blackpowder"

top down, zombie survival, shooting, story mode, objective

## Design Philosopy:
* lets get this over with.
* make one big universal piece of code that does everything and not touch it in a billion years.

## Tool used: 
SDl3, CMake, and a little bit of imagination.

# fork and branches
if you hope to build this project, you need to download SDL3(v3.2.26) and SDL3_Image(v3.2.4), and place their directory inside a file named “LocalPaths.cmake” and place it down in the root folder. 

EXample Inside of “LocalPaths.cmake”:

“set(SDL3_DIR "M:/code/libraries/SDL3-3.2.26/x86_64-w64-mingw32/lib/cmake/SDL3")

set(SDL3_image_DIR "M:/code/libraries/SDL3_image-3.2.4/x86_64-w64-mingw32/lib/cmake/SDL3_image")”
